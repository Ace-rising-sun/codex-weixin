# 验证范围

## 自动化

GitHub Actions 的 CI 在 macOS Apple Silicon、macOS Intel、Windows x64 上分别运行 Node.js 22 和 24。以仓库实际 CI 结果为准。

- 源码语法、界面脚本、版本一致性和可移植 MCP 清单。
- 消息协议、权限隔离、状态保存、并发后台保护、队列与停止。
- 四类媒体接收、Codex 输入构造、真实 SILK 解码、视频抽帧、加密上传和一次性消息提交。
- 独立历史入口、旧记录兼容、排序、搜索界面脚本。
- 在临时 Codex 配置与私有目录中安装真实插件、注册系统用户后台、读取状态、系统语音合成、停止与卸载。
- 源码包清单和校验文件，确保不含本机账号数据。

自动化中的微信传输与模型执行使用 fixture，实际编解码使用所安装的工具。测试没有代替真实手机端收件确认。

## 已有实机证据

- Mac Apple Silicon 已完成真实微信扫码、连接、文字任务、入站语音和中文识别。
- Mac 的本地语音合成、MP3 转换、本地识别、视频抽帧已实际执行。
- 语音气泡出现过接口成功但手机未显示，因此已移除，语音固定发送 MP3。

## 手机与桌面端验收清单

以下项目需要由使用者在目标平台实机确认，未勾选代表尚未形成完整验收记录。

- [ ] 新机器首次安装后，Codex 桌面端出现设置与历史入口。
- [ ] 扫码和 PIN 完成，重启后无需重复授权。
- [ ] 微信发图片，机器人正确识别画面并回复。
- [ ] 微信发语音，中文内容正确识别。
- [ ] 要求语音回答，手机实际收到并能播放 MP3。
- [ ] 图片、视频和普通文件出站均在手机实际收到。
- [ ] 视频输入能分析采样画面，并明确音轨转写情况。
- [ ] 更新后绑定与历史保留，卸载后自启动后台移除。

Windows 中文语音需要安装系统中文语音包。CI 以系统已有语音验证合成链路，不能代替中文发音和手机播放验收。
